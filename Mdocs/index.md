# Mystral Editor Documentation and Notes


These few pages contain documentation and notes for the Mystral Editor (work in progress).

[Mystral Editor - Presentation](<Mystral Editor - Presentation.md>) introduces the editor and its features. [customisation](customisation.md) documents every key of `config.json` and the `custom.css` hook, and [myst-editor-css-variables](myst-editor-css-variables.md) lists the CSS variables it refers to. [additions](additions.md) and [modifications](modifications.md) record what this fork adds to, and changes in, `antmicro/myst-editor`. The two installation guides cover the warnings macOS and Windows show for an unsigned application.
