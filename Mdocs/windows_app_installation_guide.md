## 📦 Windows Installation Guide (Microsoft SmartScreen)

Since the application does not yet have a paid digital signature certificate, the **Microsoft Defender SmartScreen** security filter will display an alert the first time you launch it:

> ❌ *“Windows has protected your computer”* (Unknown publisher).

### Launch Procedure (One-time only)

1. Download the **`.exe`** (or `.msi`) file from the Releases page.
2. Double-click the file to start the installation.
3. When the blue SmartScreen screen appears:
   * Click the **More info** link (below the main text).
   * A **Run anyway** button appears in the bottom right corner: click it.
4. The application will install and launch normally.

> **Note:** This alert will no longer appear on future launches.
